# Singlog

A singing practice tool in a web app.

Organise your practice sessions and sing against a backing track.
## Why?
I like to record my singing and listen back to figure out ways i can improve. It's hard to organise when recording within tools like Audacity and it's difficult to organise practice into date and song. Singlog comes with a much neater organisation system so its easier to practice with intention!

### Components
Built using Sveltekit 2.0

File storage currently on the filesystem but will look to getting S3 integration
